Presets

A preset sets the tone, format and situation. Pick one in the panel; the tone/format menus there override it for one run.

Global hotkey

GNOME on Wayland doesn't let apps grab global keys, so the hotkey is a GNOME custom shortcut that runs plume --toggle. To add it (Super+Alt+F by default), run the script that comes with Plume: 

/opt/Plume/resources/install-shortcut.sh

Or add it by hand: Settings → Keyboard → View and Customize Shortcuts → Custom Shortcuts → +, with the command plume --toggle.
